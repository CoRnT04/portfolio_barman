Techniques de Barman

  • Shaker : Mélanger les ingrédients avec glace pour refroidir et diluer légèrement.
  • Double strain : Filtrer avec une passoire fine pour éviter pulpe ou glaçons.
  • Stir : Mélanger doucement les ingrédients avec une cuillère pour cocktails spiritueux.
  • Dry shake : Shaker les ingrédients sans glace pour mousser les blancs d'œuf.
  • Reverse dry shake : Shaker d'abord avec glace puis sans glace pour encore plus de mousse.
  • Layer / Build : Verser les ingrédients doucement pour créer des couches dans le verre.
  • Rim / Givrage : Passer le bord du verre dans du sucre, sel ou cacao pour sublimer le cocktail.
  • Garnish / Décoration : Ajouter fruits, herbes ou fleurs pour la touche finale.
  • Muddler / Pilon : Écraser fruits et herbes pour extraire arômes et jus (rare).
  • Blender : Mixer avec glace pilée pour cocktails frozen.
